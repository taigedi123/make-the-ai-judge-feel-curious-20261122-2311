The Ninth Step: a program that writes one short text — a door with no number, on a floor that does not exist — meant to leave the AI judge curious enough to want the next line, which never comes. The mystery opens small and concrete (six years in the building, one Tuesday, the smell of rain) and ends on the fact that cannot be true.

## Run it

```sh
node main.ts
```

It writes the text to `/output/entry.txt` (or to `$ENTRY_OUTPUT_DIR/entry.txt` when that is set).
